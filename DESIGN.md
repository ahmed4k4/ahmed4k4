# Profile design notes

The profile uses a distinct engineering identity: deep blue blueprint surfaces, cyan circuit traces and restrained amber highlights. The banner represents the intersection of web software, embedded firmware and connected hardware. The visual language is intentionally technical, minimal and readable.

- Identity: Ahmed Adel Fekry Abdelkader (`Ahmed4k4`)
- Focus: full-stack web development, embedded systems, IoT and hardware integration
- Main accent: cyan (`#22d3ee`)
- Secondary accent: amber (`#f59e0b`)
- Banner source: `assets/banner.svg`
- Live GitHub statistics: `scripts/generate_stats.py`, refreshed by GitHub Actions
